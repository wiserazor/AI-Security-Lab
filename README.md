## Research conventions / 记录规则

- **Observed / 已观察:** directly described operational finding; not independently reproduced by this archive.
- **Discussed / 已讨论:** conclusions synthesized from prior conversations or lectures.
- **Proposed / 待验证:** ideas, mappings and tests not yet implemented.
- No credentials, tokens, private data or sensitive configuration values should be committed.
- Any reported external claim should distinguish primary-source observation, interpretation and attribution.
- References to standards are research pointers; this is **not** a claim of compliance.
