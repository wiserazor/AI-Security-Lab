# Research Roadmap | 研究路线与交付计划

**Origin:** 2026-08-04 conversations on transition toward AI Assurance / AI Security. This is a refreshed structure, not a claimed completed 18-month program.

## Three phases / 三阶段
### Phase A — Foundations and evidence discipline
Study model/agent architecture, threat modeling, OWASP/ATLAS, NIST AI RMF and ISO AI-risk concepts. Deliver: glossary, cited literature register, asset and trust-boundary diagram.

### Phase B — Hermes lab and measurable controls
Create tool permission matrix, isolated scenario tests, memory/retrieval safeguards, change-control record and redacted traces. Deliver: reproducible security baseline v1.0, test suite and findings register.

### Phase C — Independent AI Assurance portfolio
Build evaluation pipeline with holdout tasks and measured false positives/negatives, implement threat–control–evidence–test mapping, and adapt a GxP validation case. Deliver: assurance report with limitations and residual-risk sign-off.

## Prior 18-month topic sequence
AI foundations → OWASP/MITRE/NIST → Agent engineering → ISO 42001/23894 and relevant regulations → Evaluation/Alignment/Red Team → Assurance portfolio.
